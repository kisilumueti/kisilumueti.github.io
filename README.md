# Johnbosco Mueti — Portfolio

A responsive, multi-page GitHub Pages portfolio showcasing software development, healthcare IT, enterprise systems and digital operations.

## Pages
- `index.html` — portfolio landing page
- `about.html` — professional profile, technology stack and JBinspires
- `experience.html` — work experience, education and certifications
- `projects.html` — live GitHub repository explorer with search, language filters, sorting and pagination
- `services.html` — capability areas
- `cv.html` — embedded and downloadable CV PDF
- `contact.html` — contact details and email enquiry form

## Features
- Responsive multi-page navigation
- Dark/light theme toggle persisted in local storage
- Intersection Observer reveal animations
- Live GitHub repository explorer with search, language filtering, sorting and pagination
- Contact form that prepares an email without collecting personal data on a server
- Accessible navigation controls and reduced-motion support
- CV PDF served directly from the repository

## Deployment
No build step is required. The site uses static HTML, CSS and JavaScript and is published through GitHub Pages at:

https://kisilumueti.github.io/
